Gold project grids use self-contained SVG cells to preserve the black background, gold borders, and tinted alternate rows on GitHub. Cell images align at the top and share row heights. Column widths are 200 / 340 / 180 / 270 units: description has more room than Stack. Project names link to their GitHub organization or repository; other cells are inside picture elements to avoid automatic image links. Text is rendered as paths using DejaVu Sans.
